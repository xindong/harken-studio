用命令行操作 Harken Hub

CLI 让你不用打开 Hub 窗口，就能管理工程、Studio 版本和 Unity 集成包。它和 Hub 共用工程列表与设置。打开或创建工程时，仍会启动 Studio。

第一步：运行一条命令

在包含 HarkenHub.exe 的文件夹中打开 PowerShell，输入：

.\HarkenHub.exe --cli projects list | Out-String

返回内容是 JSON，一种便于人和程序读取的结构化文字。ok: true 表示命令成功，具体结果在 data 中。如果不在安装文件夹，请写出程序的完整路径；路径有空格时要加引号。

& "C:\你的安装路径\HarkenHub.exe" --cli help

macOS 用户可在终端中运行 Hub 应用包内部的可执行文件，后面的命令和参数相同。help 会列出当前版本真正支持的命令。

在交互式 PowerShell 窗口中，命令末尾加上 | Out-String，可以等待这个 Windows 桌面程序执行完并显示完整结果。脚本也应先等待进程退出，再读取退出码；PowerShell 中请在管道执行完后读取 $LASTEXITCODE。

第二步：找到你要做的事

想做什么命令
查看工程列表projects list
添加已有工程projects add --path "D:\Audio\Game.hsp"
打开已登记的工程projects open --path "D:\Audio\Game.hsp"
查看 Studio 版本与构建编号versions list
为工程选择 Studio 版本projects select-version --path "D:\Audio\Game.hsp" --build BUILD_ID
新建工程projects create --build BUILD_ID --name GameAudio --location "D:\Audio"
查看工程模板projects templates --build BUILD_ID
查看服务器版本versions server
下载指定版本versions download --build BUILD_ID
登记本地 Studio 构建versions add-local --path "D:\Build\HarkenStudio.exe"
查看工程集成关系integrations list
校验已安装的 Unity 集成包integrations verify --path "D:\UnityGame"
切换主题settings set --key theme --value dark；浅色为 light，跟随系统为 system
检查更新updates check --product hub；检查 Studio 时改用 studio
读取最近活动日志diagnostics logs --lines 100

表中每条命令前都要加上 .\HarkenHub.exe --cli。BUILD_ID 要替换为版本列表返回的构建编号。CLI 修改设置后会保存；已经打开的 Hub 窗口需要重新打开才能读取界面与语言改动。自动更新选项会立即通知后台服务；开启时若服务未运行，会启动后台服务，不打开 Hub 窗口。

第三步：先看清单，再确认改动

安装、修复、移除文件分两步。第一次运行命令，Hub 返回变更计划和 confirmation 确认标识。读完计划，确认无误后，在原命令后补上 --confirm TOKEN 再执行。

.\HarkenHub.exe --cli versions install --package "D:\Downloads\Studio.zip" --manifest "D:\Downloads\release.manifest"
.\HarkenHub.exe --cli versions install --package "D:\Downloads\Studio.zip" --manifest "D:\Downloads\release.manifest" --confirm TOKEN

安装包和清单路径请使用下载命令实际返回的路径。TOKEN 要换成刚收到的确认标识。文件或选项变化后，旧标识会失效；请重新阅读新计划。安装、修复、卸载 Studio 时，Windows 可能弹出系统管理员授权提示。

projects remove 只把工程移出 Hub 列表，versions remove-local 只移除本地构建登记，都不删除对应文件。versions uninstall 则会卸载已安装的 Studio 版本。修复损坏版本会替换安装目录，请先查看计划中的 changes 清单，特别注意标为 remove、将被删除的个人文件。

第四步：安装或更新 Unity 集成包

.\HarkenHub.exe --cli integrations install --path "D:\UnityGame" --source "D:\Integration\Harken"

修改前请关闭 Unity。阅读返回的文件变更清单，再使用相同参数加上确认标识执行，安装或更新所选集成包。

移除整个集成包可用 integrations remove --path "D:\UnityGame" --backup "D:\Backups\Game-integration-01"。备份位置必须是尚不存在的新目录，确认时保持同一路径。迁移、还原也采用先检查再确认的方式，完整参数见命令参考。

更新、协议与出错后的处理

工程命令成功但包含 data.warnings 时，工程改动已经保存，请阅读警告，不要重复移除。修改语言也会通知正在运行的后台服务。新建工程时，父目录必须已经存在。

先用 updates download --product hub 下载，再用 updates apply --product hub 查看更新计划。更新 Studio 时改用 studio。确认后，Hub 自身更新会关闭已运行的 Hub 窗口和后台服务，再通过更新桥接安装并重启后台服务；返回“已排队”不代表安装完成，请继续查看 updates status 和 diagnostics transactions。

需要接受协议时，先运行 legal show --product studio（Hub 协议使用 hub），阅读完整内容。只有在你同意后，才运行 legal accept --product studio，核对返回内容并带确认标识再次执行。

退出码该怎么做
0命令成功，查看返回结果。
2命令或参数有误，对照帮助修改。
3操作失败，阅读错误和操作步骤，排除原因后重试。
4需要阅读计划并确认。
5需要阅读当前协议并决定是否接受。

不要让脚本自动拿到新确认标识就继续执行。新计划需要重新审阅。自动化使用方式见 AI 命令参考，可供程序读取的定义见 JSON 命令契约。
