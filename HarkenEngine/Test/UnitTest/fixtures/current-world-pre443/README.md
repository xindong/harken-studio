# CurrentWorld historical diagnostic boundary

Decision for [#447](https://github.com/xindong/harken-studio/issues/447): pre-#443
V5, V6 and V7 bodies containing inline property Binding or Curve tables are
unsupported, including in `ReplayRawAttempt`. Decoding returns
`CurrentWorldBodyDecodeResult::Invalid`. These tables are not decoded, skipped,
converted or migrated. The retirement established by #443 remains in force.

Historical decoding supports only the existing diagnostic subset. The two old
table counts and the retired binding attachment value must be zero. A fresh
decoder exposes neither view after rejection; an existing decoder retains its
previous production or diagnostic image. Historical data must never become a
production view or enter installation, publication, playback, export or re-save.
`StrictArtifact` continues to accept only the current shipping body vintage.

V8 was introduced by #443 with both counts already fixed at zero. There is no
supported V8 format with nonzero inline table counts. Current field-slot binding
storage and production V9 data are outside this historical table family.

## Provenance

The six `.bin` files are raw CurrentWorld bodies, without an artifact or trace
envelope. They were generated by `generate.cpp` linked against the unmodified
compiler and codec at `a4a87d76ac9f2049fea8c0f9bf6c6d27164684c6`, the parent of
#443 (`0a2b0149c91ad19a01d0d2af0550d98752f16e1d`). Each body passed that revision's
encoder, replay decoder and `ValidateCurrentWorldV1` before being written.

The authoring input is a synthetic Sound 40, content revision 400, and smooth
Variable 70 with range [0, 1]. The inline variants additionally contain binding
attachment 9001, Binding 7 targeting voice volume with a 10 ms transition, and
Curve 3 with two points and one Bezier handle pair. The control variants omit
the attachment and both tables. They remain readable for diagnostics.

These fixtures contain only project-generated synthetic data, are covered by
the repository's Apache-2.0 license, and contain no third-party assets, audio,
user projects or credentials. They are test inputs, not shipping artifacts.

The payload header starts at byte 288, 312 and 316 in V5, V6 and V7 respectively.
Its retired attachment is a U64 at relative offset 67. The retired
binding/curve counts are at relative offsets 79/83; the prefix
totals are at absolute offsets 56/60. The variable row is 32 bytes, the property
row header is 56 bytes, and the payload header is 95 bytes. V7 also carries an
empty 8-byte structural ancestor header. The inline binding and curve add
32 and 40 bytes respectively.

`CurrentWorldHistoricalDecodeTest.cpp` runs all three vintages against complete
inline bodies, every truncated prefix, and individually nonzero prefix/payload
counts (1, capacity + 1, and UINT32_MAX). Separate cases keep all counts zero
and change only the retired attachment to 1, 9001, 2^32 or UINT64_MAX. Rejection
is checked in both decode modes on fresh, production-primed and
diagnostic-primed images. The controls also pin successful diagnostic decoding
and strict production rejection.

## Reproduce the frozen bytes

`generate.cpp` intentionally uses the retired APIs at the pinned revision. It
is excluded from the current test target. Do not regenerate these fixtures with
the current encoders: those encoders cannot produce the retired table family.

From the repository root in a Windows developer shell with the README build
prerequisites, use a new scratch worktree. Only the scratch root CMake file is
extended to add the generator target; compiler and codec sources stay intact.

```powershell
$fixtureDir = (Resolve-Path 'HarkenEngine/Test/UnitTest/fixtures/current-world-pre443').Path.Replace('\', '/')
$pre443 = (Join-Path (Get-Location) '.temp/current-world-pre443').Replace('\', '/')
git worktree add --detach $pre443 a4a87d76ac9f2049fea8c0f9bf6c6d27164684c6
$generatorCmake = @"
add_executable(harken_pre443_fixture "$fixtureDir/generate.cpp")
target_include_directories(harken_pre443_fixture PRIVATE "$pre443/HarkenEngine/Source/Runtime/media/include")
target_link_libraries(harken_pre443_fixture PRIVATE harken_current_world_compiler)
"@
Add-Content -LiteralPath "$pre443/CMakeLists.txt" -Value $generatorCmake -Encoding UTF8
cmake --preset windows-ninja-clang-dev -S $pre443 -B "$pre443/build-nc" -DHARKEN_BUILD_EDITOR=OFF -DHARKEN_BUILD_HUB=OFF -DHARKEN_BUILD_RUNTIME_UNIT_TESTS=OFF -DHARKEN_BUILD_EDITOR_UNIT_TESTS=OFF -DHARKEN_BUILD_RUNTIME_BENCHMARKS=OFF
cmake --build "$pre443/build-nc" --config RelWithDebInfo --target harken_pre443_fixture
& "$pre443/build-nc/bin/RelWithDebInfo/harken_pre443_fixture.exe" "$pre443/.temp/fixtures"
Get-FileHash "$pre443/.temp/fixtures/*.bin" -Algorithm SHA256
```

Compare all six digests with the table above. Run the current regression suite
with `harken_runtime_tests --gtest_filter=Pre443/CurrentWorldHistoricalDecode.*`.
