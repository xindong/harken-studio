# HarkenStudio 音频源业务结果表

表注：Sources 指文件树，引用行指 Sound → Sources；同名包含扩展名，内容比较指 hash 比较。默认单文件操作，批量情况单列。

## 1. 文件状态与显示

| 情况 | Sources 文件树 | Sound → Sources | 层级树、蓝图中的 Sound |
|---|---|---|---|
| 文件可用，波形已生成 | 正常显示 | 正常引用与波形 | 正常 |
| 非 Active 文件丢失 | 文件行消失 | 保留引用行；Audio 主题错误红，Wave 留空且不可编辑 | 不因该行缺失变红 |
| Active 文件丢失 | 文件行消失 | 同上，保留 Active 选择 | 名称、图标主题错误红 |
| 文件恢复到原引用路径 | 自动重新出现 | 恢复引用与编辑入口，波形随后刷新 | 解除缺失红色 |

表注：Active 按当前平台和预览语言判断。文件缺失保留资源 ID、引用行、裁剪、循环和 Active；文件存在但无波形，不等于文件缺失。

| 语言状态／操作 | Sources 显示与操作范围 |
|---|---|
| 未开启 Language | 显示普通音源组，不随 Toolbar 语言切换；普通组与语言组数据分别保留 |
| 开启 Language | 显示全部项目语言组，Toolbar 当前语言置顶，其余按项目语言顺序；各组行号从 1 开始；切换语言清除行选择 |
| 语言组为空 | 仍显示分组标题与表尾加号，可直接拖入；删除组内最后一行后取消选择 |
| 文件导入／Add existing | 固定写入打开操作时的语言组；操作期间切换 Toolbar 不改变目标 |
| 引用所属语言已移除 | 表下方提示，可整体迁移或删除；修复前禁止编辑 |
| 语言列表为空 | 新项目默认状态，允许删除全部语言；Toolbar 隐藏语言下拉框 |
| 重新打开工程 | 恢复本机按项目保存的语言与平台；语言选择无效时使用项目首个语言 |
| 撤销／重做语言列表编辑 | 恢复原列表及其引用可用性，包括旧项目的历史名称 |

## 2. 导入落点

| 入口／落点 | 如何确定操作目标 | 业务结果 |
|---|---|---|
| Sources 文件夹 | 该文件夹 + 来件文件名 | 导入文件，不创建 Sound |
| Sources 标题／空白 | 项目音频根目录 + 来件文件名 | 同上 |
| Sources 文件行 | 该行的父目录 + 来件文件名 | 按目录导入，不直接替换落点行 |
| 层级树／蓝图中的 Sound | 当前语言组内的同名缺失引用 | 有匹配则恢复；否则追加引用行 |
| Inspector Audio 引用框 | 引用框自身接受的单个项目音频资源 | 只替换该行引用，显示引用框边框；拒绝的拖入不转为组内导入 |
| Inspector 的具体音源行（引用框外） | 落点行所属语言；条目目标用于消除该组内的恢复歧义 | 在落点组内恢复或追加 |
| Inspector 语言分组标题／组内表尾拖入 | 落点所属语言组，包含空组 | 在落点组内恢复或追加；选中行不改变目标语言 |
| Inspector 公共表头／组外空白拖入 | Toolbar 当前语言 | 在当前语言组内恢复或追加；选中行不改变目标语言 |
| Inspector 分组表尾 → Import from file | 按钮所属语言组 | 在指定组内恢复或追加；不切换工作区语言 |
| Layer／Container／Track | 对象内部 | 每个文件创建一个子 Sound |
| 允许导入的树空白／Layer 分类根／蓝图空白 | 根层级 | 每个文件创建一个根 Sound |
| 蓝图 Bus | 根层级及该 Bus | 创建根 Sound，输出到该 Bus |
| 层级树 Bus／工程对象 Folder／不支持的对象或落点 | 无合法目标 | 拒绝导入 |
| 外部文件夹 → Sources／层级树／蓝图 | 递归取出音频，按上述落点处理 | 不保留来件目录层级；Inspector 当前不支持普通目录拖入 |

表注：从 Sources 拖入 Sound 或 Inspector，同样按上表处理；从 Sources 拖回 Sources 是移动文件。未开启 Language 时使用普通组，不跨语言或休眠组寻找缺失引用。

Inspector 的组内导入高光仅围住目标语言组的标题、音源行和表尾；拖到公共区域时高光对应当前语言组。引用框使用自身的拖入校验与高光，外部文件可拖到引用框外的行区域、组标题或表尾。

## 3. 导入时的文件结果

表注：Sound／Layer 等先复用输入本身对应的项目资源，否则使用项目音频根目录；Sound 的同名缺失恢复优先于下表。

| 目标路径状态 | 与现存文件的内容比较 | 导入 Sources | 导入 Sound／Layer 等 |
|---|---|---|---|
| 文件和记录均不存在 | — | 新建资源 | 新建资源 |
| 原记录存在，文件缺失 | 不比较旧内容 | 恢复文件，沿用 ID，不弹确认 | 同左 |
| 文件和记录均存在 | 相同 | 复用资源，无新增操作 | 复用资源，仍追加引用／创建 Sound |
| 文件和记录均存在 | 不同 | 确认替换；沿用 ID，全部引用使用新内容 | 自动使用唯一文件名，新建资源；不替换原文件 |
| 文件存在，尚无记录 | 相同／不同 | 相同则登记；不同则确认替换后登记 | 均使用唯一文件名另存，新建 ID |
| 另一个路径有同名或同内容资源 | 相同／不同 | 按本次目标路径处理，不恢复或合并另一处资源 | 两个已登记资源保持各自 ID，不按内容合并 |

表注：恢复、替换共享文件会影响全部引用方，保留原引用行、裁剪、循环和各平台 Active。取消替换不改动对应资源。

## 4. Sound 同名缺失恢复

| 目标组的情况 | 判断因素 | 业务结果 |
|---|---|---|
| 唯一同名缺失资源 | 完整文件名；不看旧 hash、来件目录或默认目标路径 | 放回该资源原路径，沿用 ID；不弹确认、不新增行 |
| 多行同名缺失，都引用同一资源 | 资源 ID 相同 | 恢复一次，所有行恢复 |
| 多个同名缺失资源 | 资源 ID 不同 | 拒绝歧义项，提示拖到具体行；不按 Active 猜测 |
| 收到目标语言组内的同名缺失条目目标 | 该条目的资源 ID | 恢复该行对应资源，消除同名歧义 |
| 拖到健康行或不同名的行 | 落点行所属语言 | 继续匹配落点组；无匹配则追加，不替换落点行 |
| 同名来件是项目内另一资源 | 缺失目标与来件各自的 ID | 复制内容恢复缺失资源；来件保留自身 ID |
| 无同名缺失，或缺失仅在其他语言组 | 目标组没有匹配 | 正常追加；不因其他组缺失改变导入目标 |
| 拖入 Layer／Container／空白 | 文件目标路径 | 可恢复该路径的缺失资源，但仍创建新 Sound |

## 5. 引用操作

| 操作 | 文件与引用结果 | Active 结果 |
|---|---|---|
| 文件导入空的引用组 | 追加引用，底层文件可新建、复用或恢复 | 首个成功新行成为 Active |
| 文件导入已有引用的组 | 恢复或追加；重复导入可再加一行 | 保留原选择，包括未选择 |
| 分组表尾 → Add existing | 在按钮所属语言组追加引用，不复制文件；普通模式使用普通组 | 保留原选择；当前不自动选首行 |
| Audio 选择器更换资源 | 只更换这一行；保留行身份、裁剪、已有循环 | 保留 |
| 删除引用行 | 只删行，不删共享文件 | 清除指向该行的选择；平台回退共享选择 |
| 行排序／裁剪／循环编辑 | 只修改引用，不改共享文件 | 保留 |
| Relink | 所选文件写入原路径，沿用 ID，全部引用使用新内容；名称可不同 | 保留 |

## 6. 改名、移动与外部改写

| 操作与情况 | Studio 内操作 | 软件外操作 |
|---|---|---|
| 普通改名／移动到新路径 | 原 ID 不变，原引用继续可用 | 旧资源缺失；新路径登记新资源，旧引用不跟随 |
| B 改名为已缺失且有记录的 A | 弹窗确认；保留 B 的 ID 与原引用，A 的引用改用 B 并恢复；取消则不变 | A 沿用原 ID 恢复，B 沿用原 ID 缺失；各自引用归属不变 |
| 移动文件／改名文件夹，目标被缺失资源记录占用 | 拒绝，不自动合并 | 按路径恢复目标资源，原路径资源缺失 |
| 目标已有实际文件 | 文件改名使用唯一名称；拖动移动拒绝冲突 | 以文件管理器最终留下的路径和内容同步 |
| 原路径内容被改写 | 通过替换／Relink 处理 | 沿用 ID，全部引用使用新内容，刷新波形 |
| 删除／恢复音频或其目录 | Sources 当前只允许删除空文件夹 | 按各文件原路径显示缺失／恢复 |
| 项目外的导入原件被删或改写 | — | 不影响已复制进项目的文件 |

表注：B→A 的内部恢复保留双方引用行的裁剪、循环和各平台 Active，覆盖全部语言及休眠组；整次操作可撤销。

## 7. 批量与冲突

| 情况 | Sources | Sound／Layer 等 |
|---|---|---|
| 重复列出同一输入路径 | 只处理一次 | 只处理一次 |
| 不同路径、同名同内容 | 同一目标只导入一次 | 普通导入分别追加／创建；命中同一缺失资源只恢复一次 |
| 多个版本竞争同一目标 | 弹窗选择版本；目标缺失也要选 | Sound 引用恢复拒绝冲突项；其他按第 3 节逐个处理，已登记输入沿用原 ID |
| 确认期间来件或目标发生变化 | 中止，重新导入确认 | — |
| 部分文件无效 | 普通新增可部分成功；读取或替换校验失败则整批中止 | 报告失败，成功项保留 |

## 8. 撤销与保存

| 操作／条件 | 业务结果 |
|---|---|
| 撤销新复制且未保存的导入 | 删除本次项目副本和资源记录，撤回新增 Sound／引用；保留外部原件 |
| 撤销使用既有项目文件，或已保存过的导入 | 保留文件及 ID，只撤回新增 Sound／引用 |
| 重做导入 | 恢复原 ID、对象与引用；不依赖外部原件仍在 |
| 撤销恢复／替换 | 回到原缺失状态／原内容；共享引用同步恢复原状 |
| 撤销 B→缺失 A 的内部改名 | 恢复 B 原路径、A 原缺失记录和双方原引用 |
| 保存后重新打开 | 保留保存时的引用状态，按磁盘现状显示文件是否缺失 |
| 放弃未保存改动 | 撤回未保存的 Studio 操作，引用回到最近保存状态；不撤销外部文件操作 |
| 撤销文件操作失败／重做遇到占用 | 报错；回退成功时保持操作前状态；不强行覆盖冲突文件 |
| 纯重复 Sources 导入／全部拒绝 | 不增加撤销步骤 |

| 当前边界 | 当前结果 |
|---|---|
| 文件仍存在但内容损坏 | 导入失败；不等同于缺失文件的隐藏与红色 |
| 操作失败后的回退也失败 | 报错并清空失效撤销历史，不能保证完整复原 |
| 放弃关闭时文件删除或回退失败 | 仍可关闭，不能保证文件完整回退 |
| Studio 文件操作后，同路径又被外部改写 | 撤销／放弃可能覆盖或删除后来的内容，当前不另做版本确认 |

## 9. Source 淡入淡出

| 操作／条件 | 业务结果 |
|---|---|
| 默认状态 | Fade In、Fade Out 时长均为 0；初始曲线为普通上凸二次曲线，归一化淡入为 `y = 2t − t²`，淡出与淡入沿时间方向镜像；已有保存的曲线保留原形状，不迁移 |
| 编辑入口 | Sound → Sources 引用行的 External Editor，直接在波形上编辑 |
| 波形预览 | Source Editor、Sources 引用缩略图、Grid 选择预览、Blueprint 和 Timeline 共用 Source 波形视图，由公共渲染器统一处理 Trim 与 Fade；按包络缩放振幅，素材库显示原始波形 |
| 预览更新 | 编辑器拖动时本地实时预览；提交、撤销和重做复用 Trim 的 `sources` 变更通知，所有引用预览自动更新；原始波形缓存共享，同文件的不同 Source 引用各自应用设置 |
| Trim 交互 | 仅顶部抓手可拖动、双击或右键编辑裁剪；主体竖线只作位置指示，不拦截 Fade 点 |
| 拖动顶部锚点 | 水平调整该侧时长；淡入、淡出不可重叠 |
| 曲线形状 | 每侧固定两个锚点，两排分别对齐波形上、下两侧的 0 dB 刻度，跟随振幅显示和窗口尺寸；底部固定在裁剪边缘，贝塞尔手柄调整形状，不增删锚点 |
| 纵向显示 | 波形始终适应编辑区高度，无独立纵向滚动或缩放控件；上下 0 dB 刻度线使用首要边界色，与普通网格线区分 |
| 边缘点显示与命中 | 沿用公共曲线渲染器的边缘留白，完整显示锚点和手柄；右侧保留贯穿上下的独立窄列分区，以刻度区底色填充，时间轴与底部横向控件止于其左边界；绘图区外露出的点仍可点击、悬停和右键，命中尺寸随 UI 缩放 |
| 形状操作 | 选择曲线显示手柄；线段使用上下箭头鼠标并沿用现有二维塑形，锚点和手柄使用手型鼠标；Shift 拖动手柄按 45° 吸附，Alt 拖动锚点可拉出对应手柄 |
| 精确编辑与预设 | 双击或右键输入时长；右键提供共享的七种正方形 SVG 曲线图标预设，依次为 S、强上凸、上凸、Linear、下凹、强下凹、镜像 S，不显示名称；普通上凸与下凹分别为二次曲线 `y = 2t − t²` 和 `y = t²`，两种 S 关于归一化坐标的 `y = x` 对角线镜像；预设仅改所选左锚点到右锚点之间的形状，右键曲线选择左锚点，右锚点没有右邻段时禁用预设；右键仍可移除淡入淡出 |
| 改变裁剪 | 保留淡入淡出时长；两侧时长之和超过剩余片段时，按比例缩短至片段长度 |
| 更换或更新为更短的音频 | 按有效裁剪长度自动缩短实际 Fade 时长，保留曲线形状；调整随 Source 保存 |
| 拖动与取消 | 松手提交一次修改；Esc 取消当前拖动 |
| 数据归属 | 保存于每条 Sound Source 引用，时长以采样帧记录；不改写共享音频文件 |
| 保存／撤销／重做 | 时长、曲线随 Source 一起保存和恢复；旧项目默认没有淡入淡出 |
| Source Editor 试听 | 绑定 Sound Source 时按源文件坐标应用淡入淡出；从中间定位或循环区间试听不重新锚定包络；素材库文件试听仍使用原音频 |
| Source Editor 试听失效 | 提交编辑、撤销／重做或源文件内容变化时停止旧试听，下次播放重建；运行时清空或重启后可直接重新播放 |
| 对象试听与打包 | 共用媒体处理，在裁剪后、重采样与调度前置静音之前将包络写入 PCM；引擎直接播放处理后的媒体，不再重复计算 Source fade |
| 转换缓存 | 有效淡入淡出时长与曲线参与派生媒体身份；修改、撤销与重做后使用对应媒体，未启用的曲线形状不生成不同派生媒体 |
