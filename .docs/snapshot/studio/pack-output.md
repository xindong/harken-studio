# HarkenStudio 打包输出快照

## 输出配置与产物

工程 `.hsp` 的 `content.audio.renderSampleRate` 和 `content.audio.channelConfig` 保存音频编译目标；`content.deployPlatforms` 保存发布平台定义，`content.deployLanguages` 保存发布语言列表，允许没有语言。`content.metadata` 仅保存工程名称。

| 配置／产物 | 默认值或位置 | 当前内容与边界 |
|---|---|---|
| Publish Directory | 工程目录下 BuildPacks | 以工程目录为相对路径基准，无法相对化时保留绝对路径 |
| Waveform File Directory | BuildPacks/Waveforms | 与发布目录采用相同路径保存方式 |
| Pack 包体 | 平台目录下的 Init.bytes、Action 包等 | Init 始终包含，未变化时可复用 |
| 包伴随 JSON | 每个 .bytes 同目录、同名 .json | 必含 schemaVersion 和名称映射；可附加 metadata、waveforms |
| Export Project Information | 默认关闭 | 开启后在发布根目录输出 Project.json，与平台目录并列 |
| Export Pack MetaData | 默认关闭 | 在本次构建包的伴随 JSON 中写入 metadata |
| Export Wave Buffer | 独立开关 | 在波形目录输出按内容 SHA-256 命名的 `<hash>.vkd`，并在伴随 JSON 写入 waveforms |
| 配置提交 | 编辑完成即更新项目，支持撤销 | 写入工程文件仍需 Save；保存与发布先提交有效编辑，无效输入标红并恢复旧值 |

表注：Project.json 是供集成侧按需使用的可选项目元数据；元数据及波形开关不改变 .bytes 包体或原有名称映射。

## 导出范围

| 入口／选项 | 当前范围与结果 |
|---|---|
| Export Platforms | 指定常规及右键导出的目标平台；不限制表格观察或勾选范围 |
| Export Checked | 按各目标平台及语言的包勾选导出；未选平台时按钮禁用 |
| Export All | 导出全部包，不改变已有勾选状态 |
| Force Re-export | 默认关闭；开启时强制重新生成本次范围内的包，仅作用于常规 Export／Export All |
| Self-cleaning | 默认开启；所选平台全部成功后清理整个目标目录，仅保留本次有效产物；关闭时保留退出清单的文件 |
| 右键 Export／Force Re-export | 以点击的 Action 包及对应清单为内容更新目标；忽略底部两开关，不清理，保留其他包内容与既有 Init，缺少 Init 时创建 |
| 分语言导出 | 各语言按独立选择出包；同语言 PostAction 依赖被取消勾选时报错 |

表注：Self-cleaning 包含取消、删除或改名的平台目录，以及任意后缀文件和 Unity .meta。右键单包导出不自动导出依赖包，也不检查混合新旧包的共享内容兼容性。

## 独立构建入口

GUI、IPC 与 Harkenizer 共用 HarkenizerCore，覆盖工程构建计划、媒体准备、资源编译调度、共享逻辑编译、包体装配、校验、所选平台发布、根目录 Project.json 和自清理。内核为内部静态库，不新增 DLL；独立 packc 程序退出。主打包链直接调用资源编译库生成内存条目，不启动私有 worker。旧 worker 入口保留给仍使用文件资源接口的调用者。

| 构建边界 | 当前分工 |
|---|---|
| GUI 输入 | 借用当前工程对象并持有工程生命周期，包含未保存编辑；全程模态构建窗口冻结编辑，不复制工程树，也不隐式保存 |
| IPC 输入 | 保留请求语义、选择范围、进度和结果接口；构建期间拒绝工程修改命令，继续允许查询和取消 |
| 命令行输入 | 完整读取已保存工程，不创建编辑器窗口或音频运行会话 |
| 资源编译 | 衍生 PCM 直接生成媒体条目，与总线等资源进入最终组包；绑定在最终归属确定后生成；不写出再拆读 `.media`／`.resident` 中间包 |
| 资源故障 | 媒体准备或条目编译失败归入当前平台；后续平台按原调度规则处理 |
| 产物与发布 | 包格式、媒体算法、条目顺序、伴随文件、取消检查和平台事务沿用原规则 |

构建窗口显示平台、包、处理阶段和进度。取消按钮、Esc 和关闭请求均请求取消，直到后台构建退出才关闭窗口；Publisher 表格只保留构建结果，不再绘制行进度。工程文件和媒体文件的监视通知延后到构建结束，随后再处理外部修改与重载。

```text
Harkenizer list-targets <project.hsp> --json
Harkenizer generate-packs <project.hsp> --all --platform-id <UUID> [--platform-id <UUID> ...] --self-clean <on|off> [--output <directory>] [--force]
```

| 合同 | 当前规则 |
|---|---|
| 工程读取 | 只读完整已保存工程；无需启动 Studio；不保存、升级或恢复工程事务 |
| 工程占用 | Studio 已打开同一工程时拒绝执行，不激活 Studio 窗口 |
| 构建范围 | 显式指定全部包、平台 UUID 及自清理开关；沿用工程语言、元数据与波形设置 |
| 输出目录 | 默认使用工程配置；覆盖参数中的相对路径以工程目录为基准 |
| 目标发现 | JSON 提供 projectId、平台 id/name/basePlatform、语言、Action stableId/name |
| 返回值 | 成功 0；失败 1；用法错误 2；取消 130 |
| 取消边界 | Ctrl+C 请求现有取消流程；已提交平台保留，未完成整次发布不执行根目录最终收尾和自清理 |
| 部署 | 随 Studio 的运行库和 schema 交付；Windows 为 Harkenizer.exe，macOS 位于应用包 Contents/MacOS/Harkenizer；无需独立 packc 或新增内核 DLL |

## 构建输入与复用

GUI、IPC 与 Harkenizer 使用同一个 `ProjectPackBuildService`。一次请求借用冻结的工程对象，按平台顺序执行；媒体路径及转换配置由快照捕获。工程身份在本次请求内计算并供各平台共享，下次请求重新计算，即使调用者复用了快照对象。身份包含实际对象层级、顺序、组件与属性、语言、被 Sound 引用的源绑定和文件覆盖，再加入当前平台定义；notes、color、文档头、编辑器文件位置、未引用资产及仅影响 Project.json 的信息不参与包身份。仍需遍历工程图、规范化输入和计算逻辑身份，不以 dirty 标志或文件监视通知直接判定可以跳过。

完整链路如下：

1. 校验目标平台及输出位置，取得输出根锁、项目 `.cache/pack/.build.lock` 和选中平台锁，恢复未完成发布。项目缓存锁覆盖整个服务请求，同一工程不能同时维护不同输出目录的缓存。
2. 读取各目标当前状态，比较工程／编译器／请求身份，检查该目标实际依赖的源内容身份及已知产物状态。完整命中则恢复发布证明、警告、统计和 Skipped 记录；不读取 PCM、整包或伴随 JSON，也不创建编译上下文。
3. 全部选中平台先通过写入预检。未命中目标在预检中完整检查旧发布，检查结果、计划和仍持有的锁交给平台构建继续使用；构建阶段不重复做同一次旧发布检查。预检不保留旧 PCM，避免同时持有所有平台的已解码旧数据；真正复用资源时仍按需读取旧包资源。检查覆盖实际替换／删除路径；容量等在编译后才确定的新增写入仍在确定后检查。
4. 对未命中目标建立 Action 依赖闭包和媒体选择。先查询源身份、音频头及衍生媒体；需要转换、导出波形或无法可靠读取原生源状态时，才复制稳定源文件。媒体就绪后，同平台同语言的选中闭包合并编译一次，完成资源归属、绑定装配和包体写入。
5. 未变化而保留的文件仍复制到暂存目录，与本次新写入文件共同组成完整发布。暂存平台产物统一验证一次，包含包体、伴随 JSON 和依赖关系。导出包元数据时，之前的包体解析用于生成对象清单；普通构建不增加该次完整读取。平台提交前确认已用源未改变，再执行原有发布事务。成功结果携带绑定当前平台锁的发布证明，供根目录收尾使用。
6. 根目录收尾前再次确认已用源，防止先完成的平台依赖在后续平台构建期间变化。全部成功时处理 Project.json 与 Self-cleaning；部分成功使用部分收尾。成功收尾后更新已实际构建的目标状态及发生变化的源状态。相同 Project.json 保留原文件；没有替换或删除时不创建根目录发布事务。

Force Re-export／`--force` 只使本次范围内的包不走相等跳过，同样执行预检、构建、暂存验证、发布、状态保存及清理。它不进入缓存目录或缓存身份，也不清空源／衍生媒体；有效的源身份与转换结果仍可复用。强制构建完成后的普通构建可以直接使用刚写入的目标状态。转换回退或可选波形失败仍保存成功发布事实及媒体引用，但不赋予整目标跳过资格。

### 打包缓存所有权

打包专用持久状态只维护以下结构；输出 `.bytes`、伴随 JSON、Project.json 和导出波形属于发布目录。编辑器的其他缓存不纳入打包身份。

```text
.cache/
└── pack/
    ├── .build.lock
    ├── sources.json
    ├── targets/
    │   └── <SHA-256(platform-output-directory)>.json
    └── media/
        └── <conversion-key>.pcm
```

| 文件／记录 | 生产者 → 消费者 | 必要内容与用途 |
|---|---|---|
| `.build.lock` | 构建服务 → 同工程后续请求 | 仅在服务持锁期间存在，串行维护目标状态和共享媒体；不是构建历史 |
| `sources.json` | `SourceContentCache` → `BuildSourceInputs` | `version`；`sources` 按规范化源路径保存 `state` 和内容 SHA-256 `digest`。原生状态用于决定是否重读内容；每个源一份摘要，跨平台和进程共用；不保存输出文件摘要 |
| 目标状态头 | `PackBuildState::save` → 恢复及回收 | `version`、实际 `directory`、`platform`、当前请求 `identity`。platform 用于回收已从工程移除的平台目标。每个平台输出目录只有一份当前记录；选择变化覆盖该记录，不生成选择历史；force 不影响身份 |
| 目标源依赖 | 平台实际访问范围 → 目标恢复 | `sources` 保存依赖源 ID；`sourceIdentity` 汇总这些 ID 与源 SHA-256。各源摘要由源状态表持有，目标不重复保存逐源摘要 |
| `packs` | 已验证发布 → 资源复用及根目录收尾 | 以相对包路径为键，保存名称、稳定 ID／类型、包依赖、包体 `state`、`companionState`；需要资源复用时成对保存 `resourceFingerprint` 与对应的 `contentHash`，需要波形时保存其路径／状态。语言及伴随路径由包路径推导；不保存内容修订、重复全目录文件清单或整份伴随 JSON |
| `units`、`counts`、`warnings` | 本次结果 → 下次结果恢复 | unit 的 key、包路径、来源类型、对象 GUID；仅有警告时保存警告，仅省略项保存额外名称。counts 保存对象／媒体／Action 数量。语言取包路径，平台描述取当前工程，大小和修改时间取已知产物，不重复落盘。汇总警告与单项诊断各自恢复，二者内容和展示范围不同 |
| `packs[path].media` | 各包实际使用集 → 缓存清理 | 每个包引用的转换 key；重建包替换自己的引用，保留包沿用自己的引用。清理汇总所有目标当前包引用，不累加过往部分构建的媒体 |
| `<conversion-key>.pcm` | `SoundSourceDerivative` → 媒体资源编译 | key 由源内容身份、裁剪、循环、调度偏移、实际重采样目标和转换格式版本构成；等价转换跨平台共享。文件含 40 字节头、32 字节内容摘要及交错 float PCM，不另存 JSON、WAV 或逐文件完成标记 |

PCM 头只包含 magic、格式版本、采样率、声道数、循环起止和媒体修订，读取端分别用于识别格式、校验布局、重建媒体描述及复用修订；帧数由载荷长度和声道数推导。摘要覆盖头和样本，供实际载入时确认内容并作为资源身份；媒体已经载入后不再为同一请求重新解码或另算身份。它不是完整工程或平台设置的副本。未经过持久目标状态管理的直接导出 API、运行时 Current World 和资源专用调用只使用内存衍生媒体，不向该目录留下无法追溯的转换文件。

源状态与目标状态以版本化 JSON 原子保存，没有额外 checksum／payload 信封。成功收尾前不提交新的目标记录；完整命中不重写记录，内容未变的源表也不重写。缓存不可用时重新构建，保存失败只影响后续复用。

### 检查与清理边界

持久源摘要只在源状态变化或无法可靠复用状态时重新计算。支持的原生状态包含文件身份、大小和高精度写入／变更时间：Windows 本地 NTFS／ReFS 使用卷及文件 ID、LastWriteTime、ChangeTime；macOS 本地 APFS 使用设备、inode、mtime、ctime；具备所需 ctime 精度的 Linux 文件系统使用相应信息。读取摘要前后核对状态，变化时不提交该摘要。Windows 检查拒绝同时写入或替换的句柄。音频头检查与识别时的状态绑定；生成私有副本时同步校验复制内容与已识别 SHA-256 一致，再从副本读取结构元数据，避免把不同内容的头和样本组合使用。

目标恢复只检查记录中包体、伴随文件和波形的原生状态，不对整个输出目录重新计算 SHA-256。状态无法复用、文件缺失或被替换时进入正常构建和产物验证；同大小并恢复 mtime 的常规写入仍由变更时间识别。原生状态用于普通文件变更检测，不承担静默介质损坏审计。源身份检查、平台提交前检查、根目录收尾前检查分别保护识别、平台发布和整次发布三个边界；它们不重复读取状态未变的源载荷。

根目录仍按发布／清理需要枚举文件，发现新增、删除和额外产物，但这些文件不成为通用内容缓存的条目。发布证明仅在目录、工程、平台、文件覆盖和依赖关系匹配且平台锁仍有效时使用；条件不满足时重新读取对应发布。无变化构建仍执行根目录元数据与清理职责。

源表在捕获当前媒体资产后移除已不属于该资产集合的路径，下一次成功收尾时保存。目标／媒体回收只在确实进入过平台构建后运行，包含失败或取消后的临时转换回收；全命中请求不扫描媒体缓存。回收删除格式不可用、所属平台已从工程移除或输出目录已不存在的目标记录，再删除所有保留目标的当前包都不引用的 `.pcm`。同一生命周期明确移除旧 `.cache/pack-build`、`.cache/pack-inputs` 和 `.cache/media/pack-derivatives`；不扫描或删除其他编辑器缓存。

### 构建期共享与并行

共享上下文复用对象索引、Action 目标查找、引用校验、平台适配、字段组、绑定降级和构建计划；平台、语言及选择范围仍属于计划身份。主计划只收集依赖闭包和媒体选择，不逐 Action 预编译播放逻辑；独立能力查询仍执行完整评估，本地化探测逐个释放临时闭包。

媒体准备按源 ID 分组，最多使用八个工作线程且不超过逻辑处理器数量。同源请求保持原顺序；不同源的读取、必要快照、转换和缓存写入可以并行。真实文件别名共享捕获结果，全局索引锁不覆盖文件 I/O；依赖范围切换、探测合并及源验证等待在途工作结束。媒体试探完整命中后才合并依赖，失败试探不扩大平台依赖；未选平台音源不成为当前平台依赖。

按解码、裁剪、重采样、回退和偏移的较大输出估算临时 PCM，以 64 MiB 约束同时转换，单个超预算任务独占转换预算；该预算不包含文件捕获缓冲和已完成结果，不代表进程总内存上限。结果按原 Sound 顺序汇总统计、警告和错误。取消先停止并等待工作线程，再释放未消费结果。平台之间、Action 组包、结果报告和正式发布保持原顺序。

准备好的 PCM 直接交给资源编译；相同衍生内容共享不可变样本与修订，单声道直接引用，多声道只转换一次 planar 布局。已发布包的资源复用使用包内内容身份与当前目标记录中的资源指纹。绑定在最终归属确定后只序列化一次。包按确定布局顺序写入头、目录、条目、媒体及零填充，不另造完整包内存映像；媒体引用在对应包写完后释放。缓存使用同目录临时写入和原子替换；发布恢复标记及正式发布事务沿用原有提交规则。

## 项目信息字段

| 字段 | 类型 | 含义 |
|---|---|---|
| schemaVersion | 整数 | Pack 合同版本，当前为 4，与包体及伴随 JSON 一致 |
| projectGuid | 字符串 | 项目稳定 GUID，规范小写形式 |
| projectName | 字符串 | 项目名称 |
| studioVersion | 字符串 | 执行导出的 Studio 软件版本 |
| studioSchemaVersion | 整数 | Editor 合同版本，当前为 9 |
| platforms | 数组 | 完整平台配置，每项仅含 guid、name、basePlatform |
| languages | 字符串数组 | 完整语言名称，不含 SFX；未配置时为空数组 |

表注：basePlatform 可为 Windows、macOS、Linux、Android、iOS，不含编码等处理参数。部分导出仍记录完整项目配置，不能据此推断本次输出范围；语言不转换为 GUID 或 ISO 代码，也不另列默认语言。

## 包伴随 JSON 字段

| 字段 | 存在条件 | 内容 |
|---|---|---|
| schemaVersion | 必需 | 与包体相同的 Pack 合同版本 |
| name、guid | Action 名称映射 | Action 名称与稳定 GUID |
| variables | 有 Variable／Label 映射 | 变量及标签名称映射 |
| metadata.packStableId | 开启 Export Pack MetaData | 十进制字符串，保留 64 位整数精度 |
| metadata.platform | 同上 | 项目配置的平台名称 |
| metadata.language | 同上 | 实际构建语言；无语言时为空字符串 |
| metadata.objects | 同上 | 平铺、按 GUID 去重并稳定排序的依赖对象清单 |
| metadata.objects[].guid / name / type / path | 对象清单项 | Studio 对象身份、名称、类型和工程对象路径 |
| waveforms | 开启波形导出且完整成功 | 波形文件、Sound GUID 及裁剪范围索引；路径优先相对伴随 JSON，无法相对化时使用绝对路径 |

| 对象清单范围 | 当前规则 |
|---|---|
| 常规对象 | Action、Sound、Container、Track、Segment、Layer、Variable、Attenuation |
| Bus | 仅 Init 包导出；内置设备输出根不列入，项目主总线保留原身份 |
| 共享依赖 | 可能由其他包承载；列入清单不表示完整定义位于当前包 |
| 波形关联 | Sound 的 GUID 对应 waveforms 中的 soundGuid；仅导出元数据不生成波形 |

## 发布与失败边界

| 情况 | 当前结果 |
|---|---|
| 输出目录受保护 | 禁止发布到工程根、祖先目录、AudioSources、对象目录及其子目录；符号链接解析后同样检查 |
| 旧波形目录不安全 | 可加载并警告；启用波形导出时跳过不安全产物，修改和保存仍校验 |
| 媒体检查范围 | 仅本次选中 Action 的依赖、目标平台和语言；无关缺失音源不阻止发布 |
| 启动前检查 | 先恢复未完成发布，再检查确定要替换或删除的输出；全部所选平台通过后才构建 |
| 权限检查界面 | 模态等待窗口，无估算百分比；Stop、Esc、关闭均请求取消，后台退出后解除限制 |
| 必需产物不可替换 | 只读、权限不足或占用阻止发布，列出路径；不自动改权限 |
| 原样复用产物 | 只读不阻止复用；是否重写以实际内容与最终发布清单为准 |
| 部分包发布 | Init 须通过内容及发布身份校验才能复用；容量增长可能重写未选中包的容量信息，保留原内容与媒体 |
| 媒体转换失败 | 尝试默认参数或原始文件回退并保留警告；源文件缺失、变化或回退失败仍报错 |
| 可选波形失败 | 警告，主包继续；省略不完整 waveforms 索引，回收本轮新文件，保留已有文件 |
| 波形清理无法取得锁 | 保留该目录波形并警告，其余发布继续 |
| 空步骤独立 Action／全空包组 | Skipped 并警告；不生成包，不计入构建或复用，其余包继续 |
| 无效 PostAction 依赖 | 结构错误，不能作为空包跳过 |
| 取消 | 提交前可取消；正式提交须完成或回滚；Canceled 不计为失败或已导出 |
| 失败或取消 | 保留此前成功发布的产物及项目信息 |
| 关闭项目信息导出 | 下次成功发布删除根目录 Project.json；旧 ProjectData.json 同时清理 |
| 关闭包元数据导出 | 本次重建的伴随 JSON 移除 metadata；未选中包的伴随文件保留 |

表注：部分发布可能改变选中包以外的产物，交付范围以本次所有实际变化的 Pack、清单及依赖为准。

## Publisher 状态归属

| 数据 | 保存范围 | 当前含义 |
|---|---|---|
| Name、语言分区 | 当前工程 | 由 Action 和语言依赖派生 |
| 包勾选、Export Platforms | 项目本地缓存 | 不进入工程撤销栈；包勾选不改变导出平台选择 |
| Built、Size、Modified、File、Version | 项目本地产物缓存 | 最近成功发布的快照；外部删除或替换不自动同步，Self Cleaning 已知删除同步清理 |
| Result、Cost | 当前工程会话 | GUI 与 IPC 共用；工程关闭后清空，不写缓存或工程文件 |
| Cost 统计口径 | 每包资源准备与写包 | 不包含共享编译和发布耗时，表头与单元格提示说明口径 |
| 全局阶段 | 当前构建任务 | 表格上方显示检查输出、媒体准备、共享编译、写包、验证发布或根目录收尾，以及实际构建平台；任务结束后隐藏 |
| 行进度 | 当前工程会话 | 按主 Toolbar 当前观察平台和语言显示；只有实际 Preparing／Writing 显示活动进度，成功发布到 100%，失败或取消冻结 |
| 等待状态 | 本轮参与行 | Queued、Prepared、Ready to publish 为普通状态文字；准备或写入暂存完成不代表已发布成功 |
| 新一轮发布 | 本轮参与行 | 清零进度及旧 Result／Cost；未参与行保留 |
| 清缓存 | 本地选择及产物 | 包默认全选，产物列留空；Build 配置、平台及语言仍为工程数据 |
