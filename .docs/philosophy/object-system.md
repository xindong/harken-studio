# 对象系统

一套音频中间件的骨架，是它的**对象系统**——声音设计师能创作、引擎能渲染、游戏能触发的那一批对象类型。

## 音频对象的种类与功能

### 心智模型

- 地基：**混音能力**——有承接音频内容并调制输出信号的能力，允许加效果器。
- 角色：**路由层级**——信号链的叶子节点：信号源，仅有路由出口，允许 Loop；信号链枝干节点：信号传播与塑形，有路由入口和出口；信号链根茎节点：信号传播与求和，有路由入口和出口。
- 功能：**独特能力**——处于内容层级时对音频内容的不同组织能力。

### 根据心智模型的类型区分

#### Bus 树下：

- **Bus**（混音能力 + 信号链根茎层级）：混音的节点。每个声音都汇入总线，总线施加自己的增益与效果后继续向上汇入父总线，最终抵达**master**。

#### Layer 树下：

- **Layer**（混音能力 + 信号链枝干层级）：对所有信号链叶子层级的对象的组织物，对挂载的 Sound、Container、Track、Piece 以及 Layer 批量塑形。树下的家族定位：**组织孩子**

- **Container**（混音能力 + 信号链叶子层级 + 选择能力）：容器可以包含多个 Sound 或 Container、Track、Piece，使得他们按照一定逻辑规则播放。树下的家族定位：**挑选孩子**
  1. Random 模式：按随机规则选择子对象
  2. Sequence 模式：按排列顺序选择子对象
  3. Match 模式：按一个或多个参数条件，选择唯一获胜子对象
  4. Blend 模式：选择混合表配置的全部子对象

- **Track**（混音能力 + 信号链叶子层级 + 排布能力）：把多个 Sound 或 Container、Piece 以 clip 的形式摆上绝对时间的单条泳道。时间对它只是坐标而不是节拍，无钟，可被直接触发。树下的家族定位：**排布孩子**

- **Piece**（混音能力 + 信号链叶子层级 + 对齐能力）：让多条 Track 泳道共享同一个坐标原点，并可选地为这个共享坐标系赋予音乐时间——tempo、拍号等。时钟域只能长在 Piece 上。树下的家族定位：**对齐孩子**

- **Sound**（混音能力 + 信号链叶子层级）：绑定媒体，最小的可播放单元。树下的家族定位：**孩子**

> **存在 Layer 祖先时，Layer 是孩子的隐式塑形总线，而 Bus 是信号链叶子对象的显式合并总线**

## 非音频对象的种类与功能

- **Attenuation**：描述"声音随距离如何变化"——不仅是音量，音频的几乎所有基础属性都可被调制，拥有极高的自由度。作为对象实例，可被多个对象同时引用。

- **Action**：是游戏引擎触发声音以及音频逻辑的代理。代理可依次执行若干步骤，顺序完成一整个行为。

- **Variable**：是游戏引擎侧控制音频系统的逻辑入口——一个具名的浮点输入槽。

- **Folder**：项目对象树中的物理文件夹组织节点。
