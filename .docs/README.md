# Harken 设计文档

本目录只包含三类内容，职责互补、互不越界：

- **[设计理念](philosophy/)** —— 意识形态与设计哲学的系统性
  成册：产品目标、核心原则、对象模型、世界观、术语表。
  必须自包含，不引用外部文件，不含任何具体落实内容，因此几乎不随代码演进
  而过期。判断"系统应当如何"时，以它为最终依据。禁止 AI 自主随意变更。
- **[质量规范](quality/)** —— 仓库内容产出和产品迭代过程的质量判断依据
  文档敏感并影响 PR 审核以及代码增量规则。禁止 AI 自主随意变更。
- **[现状快照](snapshot/)** —— 实际内容与预期内容的结构化
  对照表单与梳理清单，按产品分册。它诚实地承认自己会过期：以代码为准，
  发现失真就更新表单，而不是让文档默默作废。不能引用源码位置或信息，快照
  只能是可读性文档，不是索引表，因此总结来源虽然来自代码业务，但不能引用源码。
